PAWU V9.6.0 성능 안정화

변경 사항
- 채팅방 5초 전체 재조회 제거
- Supabase Realtime INSERT 수신으로 새 메시지만 화면에 추가
- 메시지 전송 후 채팅방 전체 재조회 없이 서버 응답 메시지를 즉시 반영
- 읽음 처리와 전체 채팅 조회 분리
- 앱이 다시 보일 때만 채팅방을 한 번 안전 동기화
- 하단 채팅 배지 15초 폴링 제거
- 채팅 메시지 INSERT/UPDATE 이벤트 및 화면 복귀 시에만 배지 동기화
- 홈 돌봄 요약 60초 세션 캐시 적용
- 홈 화면 포커스 복귀 때 중복 조회 방지
- Service Worker 캐시 버전 V9.6.0 갱신 및 이전 캐시 자동 삭제
- Service Worker 업데이트 시 브라우저 HTTP 캐시 우회

주의
- 이번 버전은 성능 안정화 버전이며 FCM 푸시 알림은 포함하지 않습니다.
- 앱 종료/잠금화면 소리·진동 알림은 다음 V9.6.1에서 Firebase Cloud Messaging으로 연결합니다.

검증 메모
- 소스 구문 점검 완료
- 현재 실행 환경의 내부 npm 미러에서 zod-validation-error@4.0.2 패키지를 찾지 못해 npm ci/build 전체 검증은 실행하지 못했습니다.
