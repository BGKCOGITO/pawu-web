PAWU V9.0.3 홈·PWA 리디자인 패치

적용 방법
1. 이 ZIP을 C:\Users\USER\pawu-web 에서 압축 해제합니다.
2. 파일 덮어쓰기를 모두 허용합니다.
3. PowerShell에서 실행합니다.
   npm run build
4. 오류가 없으면 Vercel에 재배포합니다.

이번 패치 내용
- 모바일 상단 헤더의 로그인/회원가입 세로 깨짐 제거
- 홈 화면을 밝은 PAWU V9 레이아웃으로 실제 소스 교체
- 히어로 글자와 장식 이미지 겹침 제거
- CTA를 한 줄형 카드로 변경해 작은 화면에서도 안정적으로 표시
- 하단 메뉴가 본문을 덮지 않도록 안전 여백 조정
- 앱 아이콘/Apple 아이콘/Maskable 아이콘 신규 파일명으로 교체
- 서비스워커 캐시명을 V9.0.3으로 변경해 이전 UI 캐시 제거

배포 후 확인
- Chrome에서 새로고침을 1회 합니다.
- 설치 앱은 기존 PAWU 앱을 삭제하고 Chrome에서 다시 설치해야 새 아이콘이 표시됩니다.
- 여전히 이전 화면이면 Chrome 사이트 설정 > 저장공간 > 데이터 삭제 후 다시 접속합니다.
