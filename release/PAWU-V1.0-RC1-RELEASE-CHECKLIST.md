# PAWU v1.0 RC1 출시 체크리스트

## 1. 자동 검사

출시 후보 ZIP을 적용한 뒤 개발 서버를 모두 종료하고 실행합니다.

```powershell
Remove-Item -Recurse -Force .next -ErrorAction SilentlyContinue
npm run release:check
```

다음 항목이 모두 통과해야 합니다.

- [ ] 환경변수 검사
- [ ] 정적 보안·구조 검사
- [ ] TypeScript 검사
- [ ] ESLint 검사
- [ ] Production Build
- [ ] `release/reports`에 PASS 보고서 생성

## 2. 보호자 핵심 흐름

- [ ] 로그인·로그아웃
- [ ] 반려동물 등록·수정·삭제
- [ ] 병원 검색·상세·전화·길찾기
- [ ] 예약 생성·조회·취소
- [ ] 건강 타임라인 조회
- [ ] 처방·복약 일정 확인
- [ ] 입원 경과·퇴원 상태 확인
- [ ] 실제 방문 후기와 사진 등록
- [ ] 즐겨찾는 병원 저장·해제
- [ ] 응급·야간 병원 조회
- [ ] AI 건강 요약과 리포트 공유

## 3. 병원 핵심 흐름

- [ ] 병원 계정 로그인 후 대시보드 접근
- [ ] 예약 승인·거절·완료
- [ ] 전자차트 작성·저장·완료
- [ ] 처방 등록 후 보호자 화면 연동
- [ ] 입원 등록·경과 공유·퇴원
- [ ] 후기 확인과 답글 작성
- [ ] 병원 운영 대시보드 통계 표시
- [ ] 직원 계정 권한 제한 정상

## 4. 데이터·권한 필수 확인

- [ ] 보호자 A가 보호자 B의 반려동물을 조회할 수 없음
- [ ] 병원 A가 병원 B의 예약·차트·입원 데이터를 조회할 수 없음
- [ ] 로그아웃 상태에서 보호자·병원 전용 API가 차단됨
- [ ] 사진·첨부파일이 허용된 사용자에게만 노출됨
- [ ] 삭제·수정 작업이 해당 소유자 또는 권한자에게만 허용됨

## 5. 모바일·브라우저 확인

- [ ] Android Chrome
- [ ] iPhone Safari 또는 Safari 호환 확인
- [ ] Windows Chrome
- [ ] 360px 폭에서 가로 스크롤 없음
- [ ] 팝업·모달이 화면 밖으로 잘리지 않음
- [ ] 뒤로가기 후 상태가 비정상적으로 남지 않음

## 6. 출시 차단 기준

다음 중 하나라도 발생하면 정식 출시하지 않습니다.

- 다른 사용자 또는 다른 병원의 데이터 노출
- 예약·차트·입원 핵심 흐름 중단
- 결제 또는 알림 관련 중복 실행
- Production Build 실패
- 반복 재현되는 흰 화면·무한 로딩
- 데이터 저장 후 유실 또는 중복

## 7. RC1 운영 원칙

- RC1에서는 신규 대형 기능을 추가하지 않습니다.
- 오류 수정, 권한, 성능, 문구, 모바일 UI만 변경합니다.
- 실제 병원과 보호자 테스트 결과를 RC2에 반영합니다.
