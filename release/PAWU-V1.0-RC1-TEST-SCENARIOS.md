# PAWU v1.0 RC1 필수 시나리오

## 시나리오 A — 보호자 예약부터 진료 완료까지

1. 보호자 로그인
2. 반려동물 선택
3. 병원 검색 및 예약
4. 병원 계정에서 예약 승인
5. 전자차트와 처방 작성
6. 진료 완료 처리
7. 보호자에서 예약 상태·차트·처방·건강 타임라인 확인
8. 방문 후기 작성

**통과 조건:** 모든 화면이 같은 반려동물과 예약을 가리키고 중복 데이터가 없어야 합니다.

## 시나리오 B — 입원부터 퇴원까지

1. 병원에서 입원 등록
2. 입원 경과 작성 및 보호자 공유
3. 보호자에서 입원 중 상태와 경과 확인
4. 병원에서 퇴원 처리
5. 보호자에서 퇴원 완료와 건강 타임라인 확인

**통과 조건:** 입원·퇴원 상태가 양쪽 화면에서 일치해야 합니다.

## 시나리오 C — 병원 권한 분리

1. 원장 계정 로그인
2. 직원 계정 생성 또는 기존 직원 로그인
3. 제한된 메뉴 접근 시도
4. 다른 병원 URL과 API 직접 접근 시도

**통과 조건:** 원장은 전체 기능을 사용하고, 직원은 부여된 권한만 사용하며, 타 병원 데이터는 노출되지 않아야 합니다.

## 시나리오 D — 출시 안정성

1. 개발 서버 종료
2. `.next` 삭제
3. `npm run release:check`
4. Production 서버 실행
5. 주요 화면 새로고침 및 직접 URL 접근

**통과 조건:** 검사 전부 PASS, 새로고침 오류와 prerender 오류가 없어야 합니다.
